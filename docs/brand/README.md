# Brand design evidence

The written case is `docs/brand-identity.md`. This folder holds the renders that
case is based on, so the judgement can be checked rather than taken on trust.

| File | What it shows |
|---|---|
| `concepts/concept-{a,b,c}.svg` | the three concepts as drawn, 64-unit grid, original palette draft |
| `concepts/concept-{a,b,c}-mono.svg` | single-ink cuts, used to test that each survives greyscale |
| `concepts/board-three-concepts.png` | A/B/C at 180 px, at 16/24/32/48 px, and mono on plum |
| `concepts/board-refinement-1.png` | gem on the letter's junction, ring separations, two-tone split, four quadrants |
| `concepts/board-refinement-2.png` | gem moved to the V apex, on light and dark |
| `concepts/board-refinement-3.png` | gem nested in the counter, favicon-simplified two-tone gem |
| `concepts/board-refinement-4.png` | two halves vs four quadrants vs diamond notch |
| `concepts/board-colour-pairs.png` | the four candidate colour pairs at 16/24/32/48/64 px on cream, white and plum |
| `concepts/masters-rendered.png` | every SVG master, light and dark |
| `concepts/png-export-sheet.png` | the PNG family at true relative sizes on three surfaces |
| `concepts/maskable-and-small-sizes.png` | maskable 512 cropped to a circle and a squircle; 16/32/48 px at 6× nearest neighbour |

Screenshots of the deployed site were taken and inspected during verification and
then deleted, per the standing rule that screenshots do not stay in the workspace.
