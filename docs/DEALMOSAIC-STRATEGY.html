Added at your request · Grocery & 10-minute delivery

Potato chips, not just phones — and India's 10-minute platforms break four assumptions

I audited every quick-commerce platform operating in India. Two things you guessed are now confirmed facts: Uber does not do groceries in India (Uber Eats India was sold to Zomato in 2020 and shut down here — Uber runs ride-hailing only), and the instant-delivery market is now a six-way fight: Blinkit, Zepto, Swiggy Instamart, plus Flipkart Minutes, Amazon Now and BB Now scaling fast. BigBasket, JioMart and DMart Ready cover the slotted/express grocery side.

But quick commerce is not "e-commerce with a faster courier". It breaks four assumptions a price engine normally relies on — and each break has an engineering answer:

Break 1

No national price

Price is per dark store, per pincode. Answer: every price carries a location scope; no pincode → no q-commerce comparison, and we say so.

Break 2

Prices move hourly

Surge and rain fees appear per session. Answer: freshness TTL drops to 15–30 min and confidence decays faster.

Break 3

Fees are conditional

Delivery is free above a cart threshold, plus handling, small-cart and packaging. Answer: a new Conditional line state — never summed as if it were known.

Break 4

Identity is a pack size

52 g ≠ 90 g ≠ 180 g. Loose produce has no GTIN at all. Answer: unit pricing (₹/100 g, ₹/kg, ₹/L) and strict variant splitting.

So here is how you actually get real grocery comparisons on day one

Layer 1 · LIVE now

Deep-link comparison

Every platform gets a pre-filled search link: "Check on Blinkit →", labelled honestly — "price confirmed on the platform, not here." Works today, needs no permission, monetisable where an affiliate programme exists.

Layer 2 · the differentiator

Mosaic Community Price

Shoppers report what they just paid — platform, pincode, pack size, price, timestamp. Shown in its own trust tier ("Community-reported · 12 min ago · 712201"), never merged into a verified total, drops out of ranking after 90 minutes. Pincode only — no GPS, no address.

Layer 3 · dormant

Seven platform connectors

Blinkit, Zepto, Instamart, BigBasket, JioMart, Flipkart Minutes, Amazon Now — full interfaces, shipped pending_approval, visible in admin health with the exact onboarding route. They switch on the day a legal feed exists.

Why Community Price is worth building

Quick-commerce prices differ by pincode and by hour. Shoppers know what they just paid; the platforms never publish it. That makes user contribution the only legal source of real Indian grocery prices at launch — and a genuine moat if the trust labelling is strict. Anti-gaming rules: one report per product/platform/pincode per 6 hours, no XP for duplicates or contradictions, every report auditable, moderation queue for spot verification.

The mark: "Prism Tessera"

Three angular tiles — coral, lime-sun, turquoise-blue — converge into one prism, with an aperture notch suggesting discovery. Three retailers, one clear answer. Pure inline SVG geometry, so it animates: tiles drift in and lock with a 40 ms stagger, then the prism catches a shine sweep. No cart, no tag, no globe, no competitor resemblance — original by construction.

Motion, all 15 required animations are budgeted in docs/04-design-system.md: shared easing tokens, transform/opacity only, ≤1.2 s per moment, no scroll-jacking, and a hard reduced-motion contract that collapses every loop, confetti and parallax to a ≤90 ms fade.

Part 13/14 · Architecture

A modular monolith, a pure engine, and an honest type system

Engine

Dependency-free core

Matching, money, ranking and confidence live in a pure TypeScript package — no I/O, fully unit-tested, reusable on client and server.

API

Hono on Node → Workers

Same route code runs locally free and on Cloudflare's free tier later. Session auth, CSRF, rate limits, Zod validation, server-side admin checks.

Data

SQLite now → Postgres later

29+ tables, real FKs and indexes, integer money in minor units. Repository interfaces mean Supabase is a driver swap, not a rewrite.

Frontend

React + TS + Vite + Tailwind

Hand-built SVG charts (zero KB of chart library), self-hosted subset fonts, bundle budgets under 180 KB gzip on the landing route.

Trust

Provenance in the type system

dataOrigin + verificationState on every offer. The UI cannot render demo prices without the watermark; a test asserts it.

Security

Scrypt + session table

No plaintext passwords, server-side revocation, per-user row filtering proven by a cross-user isolation test, admin mutations audit-logged.

Search pipeline (this is the product)

query → validate → auth gate → cache → connectors (enabled + healthy only) → normalise → identity grouping → variant disambiguation → offer build → money.calculateTotal() → rank (commission-blind) → confidence → persist snapshot → top 3 (or fewer)

Two rules the engine enforces mechanically: an offer whose total is incomplete can never be labelled the verified winner, and permuting affiliate commission rates must not change the order — both are automated tests.
